ملفات مشروع ROYA Social Bots 1.3.0

ملاحظة: تمت محاولة رفع الملفات مباشرة إلى مستودع GitHub، لكن واجهة الربط أعادت خطأ 403 عند الكتابة. هذا الأرشيف يحتوي على الملفات لتستطيع رفعها بنفسك.

طريقة الرفع من الهاتف:
1) افتح https://github.com/m3rMAX/-ROYA-SocialBots
2) اضغط Add file ثم Upload files.
3) ارفع الملفات والمجلدات الموجودة داخل هذا الأرشيف (بعد فك الضغط)، أو ارفع ملفات المصدر والـ README أولاً.
4) اضغط Commit changes.

لتحميل البلوقن للسيرفر: استخدم RoyaSocialBots-1.3.0.jar وضعه داخل plugins ثم أعد تشغيل Paper 1.21.11.
مهم: طلب تحميل Resource Pack التلقائي لن يعمل حتى تضع رابط HTTPS مباشر لملف ZIP في resource-pack.url داخل plugins/RoyaSocialBots/config.yml. الرابط الفارغ لا يمكنه تحميل الحزمة تلقائياً.
