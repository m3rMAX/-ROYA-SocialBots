ROYA Social Bots Resource Pack
Minecraft Java 1.21.11. The plugin displays custom 3D item models using legacy CustomModelData on STICK.
Install this pack on every client (or host it and configure server resource-pack delivery).
If the server uses a different pack format in its exact 1.21.11 build, Minecraft will show a compatibility notice but the custom item models should still load on matching 1.21.x clients.
